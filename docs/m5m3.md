## Summary
- **Nothing is adopted. The incumbent stays M2r_huber (0.1791).**
- **M3** is a two-tower MLP with a sum/product pair encoder, trained on the incumbent's nested stacker rows and features with a Huber + auxiliary BCE loss.
  - Primary 0.1696 (C1 .263 / C2 .154 / C3 .095), −0.0096 [−0.0162, −0.0033] vs the incumbent.
  - Seed 7: −0.0090.
  - This is the best non-GBDT model so far: it matches M2-binary (0.170), and its C3 equals the incumbent's.
- **M5 with B4 + NBR is strongly harmful.** Pooled rule −0.034; class-preserving rule −0.025.
  - B4 and NBR are constant on C3 (ρ ≈ 0.03 with the incumbent there).
  - On C1/C2 they are much weaker than the incumbent, so an equal-weight vote dilutes it.
- **M5 {incumbent, M2-binary, M1}:** −0.0074 [−0.0121, −0.0027].
- **M5 {incumbent, M3}:** +0.0015 [−0.0025, +0.0053], seed 7 +0.0031.
  - C3 rises 0.0936 → 0.0990, the highest C3 of any model so far, but the change is not significant.
  - This is the only ensemble with a positive point estimate. It fails the bar: the CI includes 0 and Δ < 0.005.
- Because nothing was adopted, no sanity control (shuffled member / permuted labels) was run, as pre-stated.

## M3 (config `m3`; `src/models/m3.py`, `scripts/run_m3.py`)
- **Architecture.**
  - Gene tower (155 label-free gene-table columns + missing indicators = 236 inputs → 128 → 64), shared by both genes.
  - Pair MLP on [e_a+e_b, e_a⊙e_b, P'] → 256 → 64, with two heads: Huber on −min(S2,0) is the score; BCE on the label is auxiliary, weight 1.
  - P' = the incumbent's 475 features (LF + RYAN + NBR + GP) as quantile-normal values plus missing indicators (722 inputs).
  - Input dropout 0.1, AdamW 1e-3, batch 2048, ≤25 epochs, patience 4.
- **Rows and training.**
  - Exactly the incumbent's fit and validation rows: gene-grouped inner fold j = s mod 5, seeds 0–2.
  - Preprocessing is fitted on the fit rows only.
  - Symmetry was checked on 20k swapped eval rows per fold and seed: max |diff| = 0 (exact).
- **Inner-validation AP.** Mean 0.153, against the incumbent's ≈0.160 on the same rows. Best epochs 0–9; two fits peaked at epoch 0, so the network overfits fast.
- **Runtime** (primary partition, CPU, 4 threads): preprocessing 429 s, training 389 s, prediction 237 s (including transforms), total 1,075 s; peak RSS 18 GB.
- **Not run:** M3 as a nested stacker feature. It would need 25 inner M3 fits per partition, which exceeds the 1 h budget (stated in the config).

## Notes for the PI
